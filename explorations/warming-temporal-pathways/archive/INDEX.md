# Historical exploration archive

This directory is deliberately excluded from Quarto rendering and the active
sidebar. It preserves superseded exploratory code and pages whose producer
inputs are no longer part of the active data catalog.

Current public routes remain available through small redirect pages in
`investigations/`; each redirect points to the current manuscript evidence
rather than silently rendering a result based on retired outputs.

Archived material must not be sourced by active QMD files or R helpers.
